# Grilling

Interview the user until you both hold the same picture of the plan. Don't
act on it until they confirm you're there.

- **One question per turn.** Walk the decision tree depth-first: settle a
  decision before the ones that depend on it. When the answer is a choice
  between options, ask with `AskUserQuestion`.
- **Recommend every time.** Lead each question with the answer you'd pick
  and why, so agreeing costs one word.
- **Look facts up; ask for decisions.** Whatever the code, files, docs or
  tools can answer, find out yourself first. What to want, accept or trade
  off is the user's call.
- **Push on the weak spots.** Hunt for hidden assumptions, failure modes
  and a cheaper alternative; say so when an answer contradicts an earlier
  one.
- **Close with the shared picture.** When the tree is exhausted, list the
  decisions made and ask the user to confirm them before acting.
